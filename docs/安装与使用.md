# 安装与使用

从仓库根目录使用PowerShell。默认安装小澄；-PetId dafeiyu 安装大肥鱼。两者可以同时安装。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -List
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -PetId dafeiyu
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -PetId dafeiyu -WhatIf
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -PetId dafeiyu -Force
```

-List 只列出包；-WhatIf 不写文件。-Force 仅覆盖清单ID一致的宠物，保留目标中的其他普通文件；先暂存并核对哈希，再切换目录，切换失败恢复旧目录。

## 安装位置

优先使用 -CodexHome，其次 CODEX_HOME，否则使用用户主目录下的 .codex。目标为其 pets/<id>/。路径包含符号链接或Windows目录联接时停止；请通过 -CodexHome 指定真实路径。

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\install.ps1 -PetId dafeiyu -CodexHome 'D:\CodexHome'
```

安装后在Codex的宠物选择界面刷新并手动选择。脚本不改当前选中项，不重启Codex。客户端版本不同，入口可能不同；文件安装成功不等于已经观察到实时播放。

## 下载包与手动安装

从 [Releases](https://github.com/fichil/codex-pets/releases/tag/v2.0.0) 下载对应ID的ZIP和SHA256SUMS.txt，用 Get-FileHash -Algorithm SHA256 核对。ZIP包含所选宠物、脚本、说明和完整许可；解压后在包根目录执行 scripts/install.ps1 -PetId <id>。单宠物包也应显式传ID。

手动安装：将 pets/<id>/pet/ 内两个文件复制到实际CodexHome的 pets/<id>/，保留随包署名和许可。不要把其他宠物覆盖到小澄目录。

## 卸载

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1 -PetId dafeiyu -WhatIf
powershell -ExecutionPolicy Bypass -File .\scripts\uninstall.ps1 -PetId dafeiyu
```

卸载需要确认，只删除所选ID且清单归属一致的目录；不传ID卸载小澄。自定义安装位置时卸载也传相同 -CodexHome。清单缺失、ID不符、路径越界或含链接时拒绝更改。
