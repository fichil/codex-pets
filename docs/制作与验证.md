# 制作与验证

## 图集约定

V2图集1536×2288，RGBA WebP，8列×11行，单格192×208。第0至8行依次为 idle、running-right、running-left、waving、jumping、failed、waiting、running、review，帧数6/8/8/4/5/8/6/6/6。第0行第6列为中性姿态，其余空格透明。第9、10行是000至337.5度、每步22.5度的顺时针观察方向。

## 小澄

旧素材原样迁入 pets/xiaocheng/；图集SHA256为 BD2FDFD08223E2B3827648C7830801DDB497FB59F7B6D90B2382C9A400A37797。原提示词、QA和2026-09-14用户确认切换的记录保留；旧QA相对路径以该宠物目录为基准。历史QA不表示本次重新观察了客户端。

## 大肥鱼

内置imagegen基于有来源记录的社区六视图重新制作基准与动作。source/prompts保存实际提示词，source/references保存采用原图，source/qa记录抽帧和最终图集哈希。原图不应被当作已经符合精灵布局的成品。

python scripts/build-dafeiyu.py 按透明连通轮廓抽帧；同一动作共享尺度，鞋部锚定，跳跃保留源图纵向位移，观察方向共享尺度。未采用试稿留在本地输出，不随发布。

python scripts/render-previews.py --pet-id <id> 从最终图集生成GIF和预览页面；小澄保留既有GIF。python scripts/validate.py 校验清单、尺寸、透明度、使用格/空格、中性姿态和QA哈希。

## 验收边界

数值校验后检查正常192×208尺寸及浅深背景下的身份、尾巴、朝向、动作、循环和方向。QA只记录实际检查，不虚构独立评审或用户确认。Codex实时播放未观察时记录 runtimeDisplayVerified=false。

生成过程不能保证逐像素复现；保留最终图集、提示词、采用原图和确定性工具。发布包经解压与SHA256回验。工具不会更改当前启用的桌宠。

下载 Release 的两个 ZIP 与 SHA256SUMS.txt 至同一目录后，运行 `python scripts/verify-release.py <目录>`。它检查外部校验值、ZIP 内全部文件清单和归属，并在 Windows 临时目录中实际安装每个独立包。
