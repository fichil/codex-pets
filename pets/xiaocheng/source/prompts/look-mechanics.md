# 小澄 3D 手办版观察机制

材质和身份以新版 canonical-base.png 为准；旧二次元图仅解释角色服装和配色。

- 双脚、下身位置和体积稳定。眼球在眼眶内整体转动，眼睑眉毛配合；头颈轻微转向，上身克制随动。禁止把整张角色旋转、扭曲、倾斜来冒充观察动作。
- 000：正面抬眼、微抬下巴；090：脸鼻向画面右，水平视线；180：正面低头垂眼；270：脸鼻向画面左，水平视线。
- 右转时露出角色右脸，左耳为远侧，左耳耳罩自然被头发/头部遮挡。左转时露出角色左脸，左耳耳罩在近侧可见。禁止为了让耳罩一直可见把它换到另一耳。麦杆与原耳罩连在一起并随头转动，不飘移。
- 各 22.5 度档位使用大致均匀的小幅眼睛和头颈变化；近垂直方向增加明确但克制的左右瞳孔/鼻尖偏向，近水平方向增加眼睑和下巴俯仰，保持斜向两轴可辨。
- 000 -> 090 -> 180 -> 270 -> 000 顺时针形成一个连贯家族，左右转头幅度对称，髋部不随头大幅转动。
- 157.5 -> 180 和 337.5 -> 000 与其他相邻档位同样只前进一步。不得在行边界突然换脸、缩放、换脚底位置、换耳麦侧别或重设光照。
- 无场景、底座、阴影、光晕、装饰线、漂浮图标、文字或新增道具。背景纯 #FF00FF，角色内部不含相近色。
