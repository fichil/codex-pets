# 大肥鱼 · 蓝色鲸鱼娘

聪明贪吃、略带傲娇的二次元 Q 版鲸鱼娘。蓝色渐变长发、蓝瞳、鲸鳍、鲸尾与蓝白女仆装，九种状态动画与十六个观察方向全部重新制作。
